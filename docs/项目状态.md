# Watch2Skill 项目状态

目标：提供能被多模态 Agent 调用的视频学习 CLI 与 Watch2Skill 技能。

代码入口：src/watch2skill/cli.py。安装：uv sync --python 3.11。

当前版本 0.3.0。已完成独立项目、Hypit 来源快照与许可证、链接/文件输入、浏览器导出输入、分段下载、字幕归一化与 YouTube 滚动字幕去重、本地 ASR、时间标记图集、补抽帧、片段裁切、词项检索、学习证据引用校验。

真实视频：BV1hfxp6HEs7，证据目录 runs/bilibili-agent-v2；导出私有地址与字幕在 .private/。原始视频不纳入 Git。可分享的学习笔记与报告在 examples/bilibili-agent/。

新增真实验证：runs/youtube-python-v2 使用 YouTube 英文自动字幕；runs/no-subtitles-sintel-v2 确认无字幕输入后使用 faster-whisper small、CPU int8。结果及覆盖范围见 examples/README.md。
